# Library Loan System with AI Assistant

A learning and portfolio project for building a Windows desktop library loan system using C#, .NET 10, WPF, a local database, and Python for AI integration.

## Project Goals

The application will eventually support:

- Local user login
- Book catalogue searching and filtering
- Borrowing and returning books
- Adding books to the catalogue
- Offline-first local data storage
- An AI assistant for catalogue-based book recommendations based of users request

## Technology

- C#
- .NET 10
- WPF
- SQLite or another suitable embedded database
- Python
